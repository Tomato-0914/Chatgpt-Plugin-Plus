# 扩展工具

这里的每个 `.js` 文件是一个 chaite 工具（继承 `CustomTool`）。插件启动时会自动把它们登记进工具库，
写入 `utils/tools/`，并放进工具组「扩展工具」；代码没有变化时不会重复写入。
也可以由主人发送 `#chatgpt同步工具` 手动同步。

## 启用

在管理面板（`#chatgpt管理面板`）的预设里，把工具组「扩展工具」勾选上即可。

## 修改与新增

- 修改工具请直接改这里的文件，然后重启或发送 `#chatgpt同步工具`。在面板里改的代码会在下次同步时被覆盖。
- 新增工具：复制一个现有文件改写，`name = '工具名'` 与 `function.name` 保持一致，`run(args, context)` 返回字符串。
  `context.getEvent()` 可以拿到当前消息的 Yunzai 事件 `e`。
- 删除工具：删掉这里的文件后，还需要在面板里删除对应工具（同步只会新增和更新）。

## 工具列表

| 工具 | 说明 |
| --- | --- |
| `get_current_time` | 当前北京时间、星期、农历 |
| `get_weather` | 城市实时天气和 1-3 天预报（wttr.in） |
| `web_search` | 联网搜索（Bing，失败或结果无关时换 360），并读取前几条结果的正文 |
| `fetch_webpage` | 读取网页标题和正文 |
| `yunzai_command` | 搜索并以当前用户身份执行其他插件的命令（跳过 chatgpt-plugin 自身，遵守命令的权限设置） |
