# 扩展工具

这里的每个 `.js` 文件是一个 chaite 工具（继承 `CustomTool`）。插件启动时会自动把它们登记进工具库，
写入 `utils/tools/`，并放进工具组「扩展工具」；代码没有变化时不会重复写入。
也可以由主人发送 `#chatgpt同步工具` 手动同步。

## 启用

在管理面板（`#chatgpt管理面板`）的预设里，把工具组「扩展工具」勾选上即可。

## 修改与新增

- 修改工具请直接改这里的文件，然后重启或发送 `#chatgpt同步工具`。在面板里改的代码会在下次同步时被覆盖。
- 新增工具：复制一个现有文件改写，`name = '工具名'` 与 `function.name` 保持一致，`run(args, context)` 返回字符串。
  `context.getEvent()` 可以拿到当前消息的 Yunzai 事件 `e`。
- 删除工具：删掉这里的文件后，还需要在面板里删除对应工具（同步只会新增和更新）。
- 以 `_` 开头的文件是工具共用的辅助模块（如 `_workspace.js`），不会登记为工具。
- 新增或替换工具时，同步更新仓库自述文件末尾的「工具对照表」：新写的工具在「是否实现」一栏标 🆕，
  主人测试通过后把 🆕 改成 ✅。

## 文件工具的范围

文件工具有两个根目录（参数 `root`），路径一律相对根目录，`..`、软链接跳出去都会被拒绝：

| | 群友 | 主人 |
| --- | --- | --- |
| `workspace`（默认）：`plugins/chatgpt-plugin/data/files/` | 查看、写入、发送 | 同左 |
| `yunzai`：整个 Yunzai 框架目录 | 不能访问 | 查看（密钥打码）、修改（自动备份）、仅私聊发送 |

框架目录的规则：

- 查看的内容经 `_redact.js` 打码，密钥、令牌、密码显示为 `***`，不会出现在 AI 面前
- 不能写入带 `***` 的内容；含密钥的文件不能整体覆盖，只能用 `file_edit` 修改不含密钥的部分，避免真实密钥被覆盖
- 修改、覆盖前自动备份到 `plugins/chatgpt-plugin/data/backups/`，用 `file_restore` 查看备份和还原（还原前的内容也会备份）
- 框架里的文件只能在私聊里发送，不会把配置原文发到群里
- `.git`、`node_modules` 谁都不能访问

单个文件查看上限 200KB、写入上限 1MB、下载上限 50MB。

## 发送卡片、文件

工具照常用 `e.reply` 发送。官方机器人发不了的内容（音乐卡片，以及发送失败的文件）由 QQBot-Plugin 交给同群的野生号发送；
野生号也发不出来时，`send_music` 会让 AI 改为告诉用户歌曲链接。

## 提醒

提醒保存在 `plugins/chatgpt-plugin/data/reminders.json`，每 20 秒检查一次，到点后用设置提醒时的机器人在原来的群（或私聊）发消息并 @ 设置的人；
官方机器人的主动消息发不出时由 QQBot-Plugin 交给野生号。普通用户最多同时 5 个提醒，只能取消自己的；主人不限。

## 风险工具（群管、shell）

`group_admin`、`shell` 由主人要求时直接执行；其他人要求时不执行，机器人会在群里 @ 第一个主人申请确认（私聊发起时私信第一个主人），
主人名单取 `other.yaml` 里当前机器人的 `master` 和 `masterQQ`，名单里的所有主人都可以确认：

- 主人回复 `#确认`、`yes`、`Y` 执行，`#拒绝`、`no`、`N` 作废（不区分大小写），处理的是当前群里最近的一条申请；5 分钟内没有确认自动作废
- 官方机器人的申请消息带「✅ 确认」「❌ 拒绝」两个按钮，按钮设置了 permission，只有主人能点（主人需要已绑定 QQ）；
  按钮里带着这条申请的编号，同时有多条申请时点哪条的按钮就处理哪条
- 非主人说 Y / N、或当前群没有待确认的申请时，消息照常交给其他插件，不会回复“暂无权限”
- 执行的内容在申请时就已经确定，确认时不能被换成别的

- 群管优先用同群的野生号执行（官方机器人一般不是管理员），需要野生号是管理员，头衔需要群主
- 撤回群友的消息交给同群野生号：引用一条消息说“撤回这条”，或按发送者（`user_id`）/ 关键词撤回最近几条；
  工具先翻野生号的群消息记录定位消息，申请确认时会列出要撤回的每一条。没有野生号的群无法撤回别人的消息
- 官方机器人撤回自己发的消息走官方撤回接口：在官方机器人的会话里引用它发的消息，或 `user_id` 填 `bot`，
  消息从 QQBot-Plugin 的本地消息记录里找（需要更新到带 `getRecentMsgs` 的 QQBot-Plugin），官方接口可能限制只能撤回较新的消息
- 接口返回的失败（如 `ERR_NOT_GROUP_ADMIN`、官方机器人撤回他人消息返回 false）会如实说明原因，不会报“完成"
- 不能对机器人自己操作；非主人不能申请禁言、踢出主人
- shell 在 Yunzai 根目录执行，输出里的密钥、令牌、密码会打码（`_redact.js`），超过 3000 字截断

## 群信息

`group_info`、`group_members`、`group_activity`、`lucky_word` 查的都是群里的信息：

- 群友只能查当前群；主人可以用 `group_id` 指定机器人加入的其他群，群列表（`group_info` 的 list）也只有主人能看
- 群资料、成员名单：官方机器人拉不全群成员，由 QQBot-Plugin 的野生号代办（同群需要有野生号，群需要已群绑定）
- 群公告、群星级、龙王 / 群荣誉、打卡、发言榜、群数据、幸运字符只能用 QQ 账号的网页登录凭据查询（`_qqweb.js`），
  一律交给同群的野生号：ICQQ 自带凭据，OneBotv11 通过协议端的 `get_cookies` 获取；拿不到凭据或凭据失效时如实说明
- 幸运字符是机器人（野生号）自己账号的；开关本群幸运字符会影响全群，只有主人和群主、管理员可以要求，且野生号需要是管理员

## 工具列表

| 工具 | 说明 |
| --- | --- |
| `get_current_time` | 当前北京时间、星期、农历 |
| `get_weather` | 城市实时天气和 1-3 天预报（wttr.in） |
| `web_search` | 联网搜索（Bing，失败或结果无关时换 360），并读取前几条结果的正文 |
| `fetch_webpage` | 读取网页标题和正文 |
| `file_list` | 列出目录里的文件（`root=yunzai` 为框架目录，仅主人） |
| `file_read` | 查看文本文件（带行号，可分段） |
| `file_write` | 新建、覆盖或追加文本文件 |
| `file_edit` | 按原文替换修改文本文件的一部分 |
| `file_download` | 把网络文件下载到工作目录 |
| `file_send` | 把文件发到当前聊天（框架文件仅主人私聊） |
| `file_restore` | 查看、还原框架文件的备份（仅主人） |
| `send_music` | 搜索 QQ 音乐并发送音乐卡片（限流时换备用接口） |
| `poke_user` | 在群里戳一戳某人（官方机器人由野生号代办） |
| `send_like` | 给某人的资料卡点赞（官方机器人由野生号代办） |
| `member_info` | 查群成员资料，或按名字搜索群成员拿到 QQ 号 |
| `group_info` | 群资料（群名、人数、群主、管理员）、群列表 / 搜索群（仅主人）、群公告、成员统计 |
| `group_members` | 群主和管理员、成员列表、某人在不在群、潜水成员、最近入群、随机抽人 |
| `group_activity` | 群星级、龙王和群荣誉、今日打卡、发言排行、群数据（需要同群野生号） |
| `lucky_word` | 机器人的幸运字符：查看、抽取、佩戴，开关本群幸运字符（需要同群野生号） |
| `at_user` | 在群里 @ 一个或几个人并附一句话 |
| `reminder` | 设置 / 查看 / 取消定时提醒，支持每天、每周重复，重启后继续有效 |
| `send_image` | 按图片地址发图片 |
| `search_image` | 搜表情包、壁纸、普通图片并直接发出（堆糖） |
| `hot_search` | 微博、百度、抖音、头条、知乎、B 站热搜 |
| `daily_news` | 每天 60 秒新闻早报、历史上的今天 |
| `bilibili` | B 站视频搜索、视频详情，可把封面和信息发到聊天里 |
| `search_chat_history` | 用同群野生号翻看较早的群聊记录，按关键词、发送者筛选 |
| `group_admin` | 禁言、解禁、踢人、改名片、头衔、全员禁言、撤回（非主人需主人确认） |
| `shell` | 在服务器上执行命令，输出打码（非主人需主人确认） |
| `yunzai_command` | 搜索并以当前用户身份执行其他插件的命令（跳过 chatgpt-plugin 自身，遵守命令的权限设置） |
