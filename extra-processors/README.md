# 扩展处理器

这里的每个 `.js` 文件是一个 chaite 处理器（`PreProcessor` 前置 / `PostProcessor` 后置，代码里写 `type = 'pre'` 或 `'post'`）。
和 `extra-tools` 一样，插件启动时（或主人发送 `#chatgpt同步工具`）自动登记进处理器库并写入 `utils/processors/`。

在管理面板的预设里勾选需要的处理器即可使用。修改请改这里的文件，在面板里改的代码会在下次同步时被覆盖。

## 处理器列表

| 处理器 | 类型 | 说明 |
| --- | --- | --- |
| `preset_variables` | 前置 | 把预设里的 `{{变量}}` 替换成当前消息的实际值 |
| `quote_context` | 前置 | 把被引用消息的发送人、时间、内容带给 AI（ikechan 版只带引用里的图片） |

### preset_variables 可用变量

| 变量 | 内容 |
| --- | --- |
| `{{bot_name}}` / `{{bot_id}}` | 机器人昵称、账号 |
| `{{user_id}}` | 当前发消息的人的 QQ 号（官方机器人：已绑定 QQ 时为 QQ 号，否则为 openid） |
| `{{user_name}}` | 当前发消息的人的群名片，没有时为昵称 |
| `{{group_id}}` / `{{group_name}}` | 当前群号、群名；私聊时为“私聊” |
| `{{date}}` / `{{time}}` / `{{weekday}}` | 北京时间的日期（2026年10月29日）、时间（22:21）、星期（星期四） |

没有列出的变量保持原样。代入的值会去掉换行和花括号，昵称最多 30 字，避免群友用昵称往预设里塞内容。

ikechan 版本身不替换预设变量，是为了让系统提示词保持不变以命中模型的提示词缓存；启用这个处理器后系统提示词会随时间和说话人变化，缓存会失效（按 token 计费时费用会高一些）。

### quote_context

ikechan 版对话时只把被引用消息里的**图片**带给 AI，不带文字；引用文件时只给一个下载地址，官方机器人上常常是“获取失败”。
所以群友引用一条消息问“这说的什么”“这个文件写了啥”时，AI 看不到被引用的内容，会说“你没发消息 / 文件”。

启用后，每条带引用的消息前面会加上：

```
【这条消息引用了下面这条消息（不是用户这次说的话）】
被引用的消息：小红（384102485），2026/11/1 15:32
明天下午三点开会，别迟到
【引用结束，下面是用户这次说的话】
```

- 被引用的消息又引用了别的消息时，再带上一层
- 文件、语音、视频后面提示可以用 `file_read`（`source=quote`）读取；合并转发提示用 `forward_msg` 读取；图片仍由插件带给 AI（非视觉模型通过 `ask_about_image` 看）
- 官方机器人没收到被引用的消息时（没 @ 机器人的消息收不到）到同群的其他协议机器人的消息记录里找
- 读取逻辑和 `chat_context` 的 `reply` 共用（`extra-tools/_quote.js`）
