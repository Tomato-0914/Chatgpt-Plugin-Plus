# 机器人排查

用户说机器人不回消息、掉线、报错、某个插件 / 功能用不了，或者让你看运行状态、日志时，按下面做。

## 谁能查什么

- 所有人：system_info 的 env（版本、运行时间、内存）、bots（各账号在线状态、协议端、收发统计）。
- 只有主人：日志和框架文件（file_list / file_read 用 root=yunzai）、环境变量（system_info 的 env_vars）、shell。
- 不是主人的人要看日志、配置或执行命令时，说明只有主人能查，不要替他发起 shell 申请，也不要转述配置内容。

## 排查步骤

1. 先 system_info 的 env 和 bots：看哪个账号离线、运行了多久（刚重启过还是一直在跑）、内存是不是很高。
2. 主人在问时再看日志：file_list root=yunzai path=logs 找最新的日志文件，file_read 读最后的部分（offset 设到接近末尾，limit 200），找 error、错误、失败、报错附近的内容。
3. 问的是某个插件：看日志里带这个插件名的报错；需要时读插件的配置文件（root=yunzai，密钥会自动打码）。
4. 还需要更多信息（进程、磁盘、网络）时，主人要求才用 shell，只用查看类的命令（如 df -h、free -m、ps、tail），不执行删除、重启、改配置的命令，除非主人明确要求。

## 怎么回答

- 先说结论：哪里有问题、最可能的原因，再给 1～3 条处理建议（如重新登录某账号、更新插件、检查配置的哪一项）。
- 报错只摘关键的一两行，不要整段贴日志；日志里的账号、密钥、地址不要复述。
- 查不到问题时如实说，并说明还可以看什么。
- 用纯文本分点，不用表格和 Markdown 标题。
