# 群文件整理

用户要查看、搜索、整理群文件，清理重复文件，把文件归到文件夹，上传、改名、删除群文件时，按下面做。
群文件要靠同群的其他协议机器人，工具说做不了时照实转告。

## 查看和查找

- “群文件里有什么”：group_files 的 list；文件多时按文件夹说个大概（每个文件夹几个文件、主要是什么），不要全部列出来。
- 找某个文件：search 关键词；用户要下载就用 url 给出链接。
- 要读群文件里的内容：url 拿链接 → file_download 下载 → file_read 读。
- 空间用量：info。

## 整理

1. 先 list 根目录和各个文件夹，弄清现在有哪些文件。
2. 把打算怎么整理告诉用户（建哪些文件夹、哪些文件移到哪里、删哪些重复的），用户同意后再动手；用户已经说得很具体就直接做。
3. 按类型归类时常用的文件夹：文档（pdf、doc、xls、ppt、txt）、图片、视频、音频、安装包（apk、exe）、压缩包；已有合适的文件夹就用已有的，不要重复建。
4. 清理重复文件：同名文件用 delete + all_matches + keep_newest，保留最新的一个。
5. 移动用 move（folder 写目标文件夹名，写“根目录”移回根目录）；QQ 群文件只有一层文件夹，文件夹不能移动、不能嵌套。

## 权限

删除、改名、移动和文件夹操作：主人、群主、管理员要求时直接执行，普通群友要求时工具会发申请，确认后才执行。
工具返回等待确认时告诉用户等确认，不要说已经整理好了。

## 怎么回答

- 做完后汇总：新建了几个文件夹、移动了几个文件、删了几个重复文件，失败的单独说明。
- 用纯文本分点，文件多时只举几个例子。
