# 开源项目

用户发了 GitHub 仓库链接、问某个开源项目是什么 / 怎么样 / 怎么装 / 最近更新了什么时，按下面做。
如果用户问的不是开源项目（比如问“这个项目”指的是工作上的事），忽略这个技能。

## 找到仓库

- 有链接或 owner/repo：直接用 github_repo。
- 只说了项目名：先用 web_search 搜“项目名 github”找到仓库地址，确认是哪个仓库再查；有几个同名的就列出来让用户选，不要随便挑一个。
- 不是 GitHub 的链接（Gitee、GitLab、项目官网）：用 fetch_webpage 读页面。

## 按问题选动作

- “这是什么 / 介绍一下”：先 info，再 readme 看项目是做什么的、有什么功能。
- “最近更新了什么”：commits（count 10）；有发布版本的再看 releases。
- “最新版本 / 下载哪个”：releases，说明最新正式版和是否有预发布。
- “怎么安装 / 怎么用”：readme，只摘安装和使用的步骤，命令原样给出。
- “有什么问题 / bug”：issues。

## 怎么回答

- 介绍项目：一句话说它是什么，再说 3～5 个主要功能、语言、星标数、最近是否还在维护（看最近推送时间，半年没动要提一句；已归档要说明）。
- 更新记录：按时间合并同类提交，说清楚改了什么，不要逐条贴提交哈希。
- 只根据工具查到的内容回答，README 里没写的不要编；README 太长被截断时说明只看了前面部分。
- 接口次数用完时如实说，并提醒主人可以在环境变量里配置 GITHUB_TOKEN。
- 用纯文本分点，仓库地址放在最后。
